.. _temporal:

Temporal parthood
=================

«temporal» is a :ref:`parthood` relation between events. The part is a temporal segment of the whole, projected out of the whole by an external temporal frame of reference, and maximal with respect to the time interval under consideration.

The first half is a temporal part of a soccer match. A morning session is a temporal part of a conference. An afternoon segment is a temporal part of a meeting.

.. figure:: /specification-figures/temporal.svg
   :alt: The first half as a temporal part of a soccer match
   :width: 75%
   :align: center

   Associations categorized as «temporal».

Both ends are classes restricted exactly to ``{event}``.
