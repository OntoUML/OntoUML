Manifestation
=============

«manifestation» connects an aspect to an event that materializes the potentiality represented by that aspect, the dispositional dimension of the aspect.

Electrical conductivity is manifested in a current flow. Fragility is manifested in a breaking. A skill is manifested in a performance.

.. figure:: /specification-figures/manifestation.svg
   :alt: Fragility manifested in a breaking event
   :width: 75%
   :align: center

   Associations categorized as «manifestation».

Allowed ends
------------

- **Manifested end.** A class of modes. ``restrictedTo`` is a non-empty subset of ``{intrinsic mode, extrinsic mode}``.
- **Event end.** A class restricted exactly to ``{event}``.

A situation triggers an event by activating the dispositions the event manifests. See :ref:`triggering`.
