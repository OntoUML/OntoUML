This specification defines OntoUML, a profile of the OMG Unified Modeling Language (UML) for ontology-driven conceptual modeling. OntoUML extends UML class modeling through stereotypes, stereotype properties, and constraints that allow models to express ontological distinctions not explicitly provided by UML.

The profile supports the conceptual modeling of a domain by distinguishing different categories of types and relations. These distinctions include, among others, principles of identity, rigidity, existential dependence, categories of part-whole relations, and classifications involving types of types. OntoUML also provides constructs for modeling endurants, events, and situations. Its modeling constructs are informed by the Unified Foundational Ontology (UFO)\cite{towards_ontological_foundations_for_conceptual_modeling__the_unified_foundational_ontology__ufo__story_2015,ufo_unified_foundational_ontology_2021, gUFO_a_gentle_foundational_ontology_for_semantic_web_knowledge_graphs_2026}, which provides the ontological foundations described in this specification.

This specification defines the OntoUML profile in terms of its extensions to UML metaclasses, its stereotypes and their properties, and the constraints governing their use. It specifies these extensions for use in UML-based modeling tools and other software implementations.

This specification does not define a new modeling language independent of UML, prescribe a conceptual modeling methodology, or standardize UFO itself. It does not require a particular tool architecture, user interface, implementation technology, or transformation from OntoUML to another modeling or ontology language.
